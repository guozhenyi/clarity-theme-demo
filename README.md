# Clarity Theme Demo

这是 hexo 主题 Clarity 的文档和演示网站。

```bash
# 克隆仓库
git clone https://github.com/guozhenyi/clarity-theme-demo.git

# 进入项目目录
cd clarity-theme-demo

# 配置主题（主题已经作为npm包安装）
# git clone https://github.com/guozhenyi/hexo-theme-clarity.git themes/clarity

# 安装依赖
pnpm install --registry=https://registry.npmmirror.com

# 启动服务
pnpm run server # or hexo server

# 生成静态页面
pnpm run build # or hexo generate
```
